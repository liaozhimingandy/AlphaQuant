数据采集

会跑：日线 → 资金流 → 筹码 → 基本面 → 龙虎榜 → 两融 → 业绩预告 → 股东户数 → 机构评级 → 新闻 → 宏观 → 市场宽度。 单类别失败不影响其它。

采集时间窗口

默认：开盘前 30 分钟（9:00）采一轮补齐， 闭市 30 分钟后（15:30）采当日定稿数据。 15:00 整去拉拿到的是未定稿数据，所以必须留这段结算时间。

打分是**多维度加权**：题材热度 + 资金链 + 筹码结构 + 技术面 + 涨停效应， 再减去风险扣分。某维度没数据时它的权重会**分摊给其它维度**（不按 0 算）； 可用维度不足 2 个时**拒绝给分** —— 维度太少就打分只会骗人。 权重与阈值都在 config/score.json，候选池在 config/pool.json。
